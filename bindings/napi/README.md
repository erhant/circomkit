# circomkit

Node.js bindings for [Circomkit](https://github.com/erhant/circomkit), built with [napi-rs](https://napi.rs).

Exposes a `Circomkit` class mirroring the Rust orchestrator. Methods are
synchronous. As with the CLI, `circom` and `snarkjs` must be installed and on
your `PATH`.

## Requirements

- Node.js ≥ 20
- Rust ≥ 1.88 and a working linker (to build the addon)
- `circom` and `snarkjs` on `PATH` (runtime)

## Build

```sh
cd bindings/napi
yarn install        # or npm install / pnpm install
yarn build          # napi build --release → circomkit.<platform>.node + index.js + index.d.ts
```

## Usage

```ts
import { Circomkit } from "circomkit";

// Load from a circomkit.json, or from a JSON config string:
const ck = Circomkit.fromFile("./circomkit.json");
// const ck = Circomkit.fromConfig(JSON.stringify({ /* ... */ }));

ck.compile("multiplier_3");

// Inline input signals are passed as a JSON string:
const input = JSON.stringify({ in: [3, 5, 7] });
ck.witness("multiplier_3", "my_input", input);

ck.setup("multiplier_3");                 // auto-downloads PTAU for bn128
ck.prove("multiplier_3", "my_input", input);
const ok = ck.verify("multiplier_3", "my_input");

const info = ck.info("multiplier_3");     // { wires, constraints, primeName, ... }
```

## API

`Circomkit.fromFile(path)`, `Circomkit.fromConfig(json)`, and the instance
methods: `instantiate`, `compile`, `info`, `clear`, `ptau`, `setup`, `vkey`,
`contract`, `witness`, `prove`, `verify`, `calldata`, `loadInput`. Circuit
inputs cross the boundary as JSON strings; path-returning methods return the
path as a string. See `index.d.ts` (generated by the build) for exact types.
