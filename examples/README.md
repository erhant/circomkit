# Examples

Two small, self-contained projects, each a full stack that you can copy as it is and run:

| Example                       | Shows                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------------- |
| [node-sudoku](./node-sudoku/) | Node.js & Vitest: witness tests, Groth16, PLONK & FFLONK with per-circuit overrides, and C witnesses.   |
| [bun-sha256](./bun-sha256/)   | Bun with a `circomlib` circuit: proving from code, witness tests, and a Solidity verifier with Foundry. |

Both need [Circom](https://docs.circom.io/getting-started/installation/), and each lists anything else it needs. For more circuits & their tests, see [Circom101](https://circom.erhant.me).
